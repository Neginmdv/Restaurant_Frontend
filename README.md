Restaurant Ordering Frontend

A responsive React frontend for a restaurant ordering web app. This project was developed as part of a university group project, where I was responsible for the frontend development.

Features:
- Dynamic Menu Interface
- Shopping Cart : Add, remove, and update quantities.
- Order Checkout Form : Validates customer details.
- Restaurant Info Page : Displays address, contact, and embedded map.
- Mobile Friendly Navbar : Collapsible menu with FontAwesome icons.

Note!
This repository contains only the frontend I developed.
The backend (APIs for products, restaurant info, and orders) was implemented by my teammates and is not included here. To fully run the app, you’ll need to connect it to a backend providing compatible API endpoints (e.g., /api/restaurant/, /api/product/, /api/category/, etc.).


Tech Stack:
- React (Frontend Framework)
- React Router (Routing)
- Bootstrap (Styling)
- FontAwesome (Icons)
